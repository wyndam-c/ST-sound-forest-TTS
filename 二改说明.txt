声林 TTS · 二改版（+ 小米 MiMo）
=================================

本版 = 上游 ST-sound-forest-TTS 2.2.6 + 新增「小米 MiMo TTS」引擎。

安装
----
1. 解压 zip，得到 ST-sound-forest-TTS 文件夹。
2. 覆盖到酒馆：SillyTavern/data/<你的用户>/extensions/ST-sound-forest-TTS/
   （保持这个文件夹名，原有设置会自动沿用，不会丢）
3. 刷新酒馆页面 → 扩展设置 → 「声林 · 多平台语音（TTS）」→ TTS引擎 选「小米 MiMo」。

配置（缺一不可）
----------------
· API Key：小米 MiMo 的 Key（官方 api.xiaomimimo.com）
· 想用免费通道：勾选「改用免费通道」，填 token-plan-sgp 那个 Key
· 合成模式：
    - 预置音色：MiMo 默认 / 冰糖 / 茉莉 / 苏打 / 白桦 / Mia / Chloe / Milo / Dean
    - 音色设计：写一段描述（性别/年龄/口音/音高/音色质感/气质），别写语速
    - 音色克隆：上传 mp3/wav/m4a（≤8MB）参考音频
· 朗读风格（可选）：全局演绎风格，预置与克隆模式生效
· 点「测试连接」验证

排错
----
· 报 CORS / Failed to fetch：勾选「经酒馆 /proxy 转发」再试（需较新酒馆）
· 401：Key 不对或没额度
· 返回是 wav，缓存面板下载也是 .wav

角色音色
--------
「多人角色音色」只在“预置音色”模式下逐个角色生效；设计/克隆模式对所有角色统一。

🌿 声林 TTS 接入指引

🐟 Fish Audio（官方 API）

  1. 打开 Fish Audio 开发者平台，用 Discord / Google 登录。
  2. 进「Developers → API Keys」点创建，复制生成的 sk-... Key。
  3. 酒馆「声林」→ Fish Audio 设置：接入方式选「官方 API」，把 Key 粘到「API Key」，点「测试连接」。
⚠️ 官方 Key 默认有少量免费额度，用完需要充值。

🆓 Fish Audio（公益中转 / 免费额度）

  1. 加入 Fish Audio 官方 Discord，点首楼链接注册获取。
  2. 酒馆「声林」→ Fish Audio 设置：接入方式选「公益中转」，填好转发地址 + 你的令牌，点「测试连接」。
⏰ 免费额度每天北京时间 0 点刷新。

🫘 小米 MiMo TTS

  1. 打开 Xiaomi MiMo 开放平台，用小米账号登录（没账号去 id.mi.com 注册）。
  2. 进「控制台 → API Keys」点「创建/申请」，复制生成的 sk-... Key。
  3. 酒馆「声林」→ 小米 MiMo 设置：把 Key 粘到「API Key」，点「测试连接」。
📖 详细文档：MiMo 快速上手。不想充值？勾「改用免费通道（token-plan-sgp）」白嫖（有日限）。
